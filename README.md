# smcclub - Premium Club Website (MERN + React + Antigravity)

## Features
- Public: Home, About, Team, Events, Gallery, Contact, Join Our Team (form with photo upload)
- Admin: Login (admin@club.com / admin123), Dashboard (stats), Applications (approve/reject/search), Members, Events, Gallery, Enquiries

## Run
1. `cd server && npm install && npm run dev`  -> http://localhost:5000
2. `cd client && npm install && npm run dev`  -> http://localhost:5173
3. First admin: POST http://localhost:5000/api/admin/init

## Tech
React + Vite + Tailwind + Framer Motion | Node + Express + MongoDB Atlas | JWT + Multer
